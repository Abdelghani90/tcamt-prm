TCAMT Lite — frontend client

Full documentation (Docker, local install, troubleshooting) is in README.md.

Quick local install (Node 13.12.0, npm 6.14.4):
  npm install
  bower install
  npx grunt serve     → http://localhost:9000

Docker (recommended):
  npm run docker:up   → http://localhost:9000

See README.md for details.
